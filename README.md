# Personal Coding Project
# 1. ⏱️ Timed Math Challenge

An interactive, graphical desktop application built with Python and Tkinter designed to test rapid mental math skills. 

## ✨ Features

* **Dynamic Equation Generation:** Automatically generates randomized math problems using various operators (+, -, *, /).
* **Real-Time Visual Timer:** Utilizes Tkinter's native `.after()` event loop for non-blocking, millisecond-accurate time tracking.
* **Instant Visual Feedback:** Evaluates user input dynamically, providing immediate visual cues (Correct/Incorrect) without freezing the UI.
* **Session Tracking:** Tracks total correct answers, incorrect attempts, and total elapsed time, summarizing the data in a modal popup upon completion.
* **Keyboard Integration:** Bound the `<Return>` key to the submit function for a seamless, mouse-free user experience.

## 🛠️ Tech Stack

* **Language:** Python 3.x
* **GUI Framework:** Tkinter (Standard Library)
* **Libraries:** `time`, `random`
